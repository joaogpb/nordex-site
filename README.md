# Nordex Soluções em Informática

Site institucional da Nordex desenvolvido com Next.js + TypeScript + Tailwind CSS.

## Estrutura

- `/` — Página inicial
- `/servicos` — Serviços
- `/locacao` — Locação de notebooks
- `/empresas` — Soluções para empresas
- `/contato` — Contato
